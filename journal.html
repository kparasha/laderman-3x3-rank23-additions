What is being measured

The Autolab hill scores exact bilinear decompositions of the general (noncommutative) 3×3 matrix-multiplication tensor over the rationals. Primary metric is rank (number of bilinear products, minimize), then support (nonzero coefficients in U,V,W, minimize). Support is not addition count. Today’s user goal is also fewer scalar additions at rank 23 (public best 56); that is tracked separately via SLPs / Lean claimed additions. Submission is a directory with a single solution.json of integer/rational factor matrices u,v,w. Held-out private replays exist on AutoLab; this machine uses local stub private files so scores here are pipeline-faithful but not the publisher’s private set.
